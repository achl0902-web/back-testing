## 사전 등록 감사
- B 값 변경: {"th":[-0.1,-0.15,-0.2]} → {"th":[-0.05,-0.1,-0.15]}
- C 값 변경: {"th":[0.5,1,1.5]} → {"th":[0.5,1,1.5]}
- 사유: 첫 check 뒤 2건. (1) B: 발동률 0% → 원인은 자료 버그(AAII 파일 열 밀림: AAII_BEAR.csv = 실제 강세−약세 스프레드, AAII_SPREAD.csv = BULL−BEAR로 무의미, 최소 −0.086). 값 변경 없이 읽는 파일만 AAII_BEAR.csv로 바꿈. 진행자가 data/macro AAII 받기 스크립트의 열 지정을 고쳐야 함. (2) C: '챔피언과 거의 같음'(th=1.0·1.5 0일, 0.5 나스닥 12일·S&P 9일) → 당일 VRP 조건을 'S29 A와 같은 최근 20거래일 기억'(win=20, 이웃 15·25)으로 바꿈. 사유: 21일 실현분산 창이 급락일을 품는 동안 VRP가 낮고, 정점은 20일선 회복보다 몇 주 앞서 와서 당일 조건과 복귀 조건이 거의 겹치지 않음. th 값 [0.5, 1.0, 1.5]는 그대로. (3) B: 둘째 check에서 th=−0.15·−0.20이 '챔피언과 거의 같음'(나스닥 24일·S&P 29일, 두 값 같은 행동) → 값을 [−0.05, −0.10, −0.15]로 옮김(−0.10은 나스닥 74일·S&P 57일로 구분됨). 이웃 [−0.04, −0.18].
