# T14 S26 A 전체를 1960~1985에서 확인 — 사전 등록 (2026-10-24, 자료 받기·계산 전 커밋)

목적: S26 A(챔피언 + S14 B 월초 창 기술 이탈 +1표 pad=2 + S12 B 달러·PPI·유가 z>1.5 중 2개 이상이면 복귀 금지)는 개선 기준 2배(A2)만 근소 미달했다. 인플레 요소는 연구 자료가 1986년부터라 T13 재확인에서 빠졌다. 그 시대 자료로 A를 통째로 시험한다. 값은 그대로(pad=2, z=1.5, 2개 이상), 결과를 보고 바꾸지 않는다.

## 자료 (1960~85에 없는 일간 자료의 대체, 미리 정함)
- PPI: PPIACO(1913~, 이미 보유), 발표 시차 50일 — 연구와 같음.
- 유가: 연구는 DCOILWTICO(1986~ 일간). 대신 FRED WTISPLC(1946~ 월간 평균)를 시차 35일로 쓴다. 지표 = 6개월(126거래일) 상승률, 같은 식.
- 달러: 연구는 Y_DXY(1980~). 대신 FRED TWEXMMTH(1973~ 월간, 주요국 무역가중)를 시차 35일로 쓴다. 1973년 이전(고정환율)은 자료 없음 → 과열로 세지 않는다(그 기간은 PPI·유가 둘 다 과열이어야 복귀 금지).
- z점수: 연구와 같은 함수(catalog.zscore).

## 판정
lib/histcheck.js와 같은 구간·점수(S&P 2배 10년 30개, 5년 40개, 점수 = IRR 중앙 + 0.5 × 최악, 챔피언 대비):
- 10년·5년 모두 ≥ 0 → **"A 1960~85 확인 통과"**: 채택 여부는 사용자 결정(D01처럼)으로 올린다.
- 하나라도 < 0 → **"A 미확인"**: S26 A를 접는다.
참고로 복귀 금지 발동률과 발동 시기(1970년대 인플레 시기 집중 여부)를 함께 보고한다.
