# S31 사용자 지시(매 스텝 요소 최적 조합을 찾아 챔피언 v2와 조합) + 아직 안 쓴 출처(data/macro) 사용. 모든 방향은 최종 전략 v2(candidates/champ_v2.js run) 위에 얹는다. A는 ELEMENTS 풀 요소 3개 조합(MW pad=2 + X4 floor=0.25 + VRS th=1, 값 고정, 새 자유 파라미터 0개), B는 새 출처 CFTC COT Legacy(E-mini 나스닥100·S&P500 비상업 순포지션/OI, 1996~ 주간, 시차 4일), C는 새 출처 + 풀 요소(VIX 기간구조 VIX/VIX3M 2007-12~ + VRS), D는 새 출처 SLOOS(DRTSCILM 1990~ 분기, 시차 45일) + 기존 요소 200일선. 자료 없는 기간에는 새 요소가 꺼져 챔피언(C는 VRS 단독)과 같다. 사전 등록 추가 기준: A는 게이트 통과 + 1960~85 S&P 2배 재확인(lib/histcheck.js) 10년·5년 모두 챔피언(v2) 이상일 때만 채택(그 시대에는 VIX·SKEW가 없어 VRS가 꺼지고 MW+X4만 검증됨, VRS 몫은 미검증으로 기록). C는 게이트 통과 + lib/recentcheck.js 2011~ 재확인(2011~2021 1·7월 시작 5년 구간, 나스닥·S&P 2배 모두 챔피언보다 IRR 높은 구간이 절반 초과이고 최악 IRR이 챔피언 이상)일 때만 채택. VIX3M이 2007-12부터라 1986~ 게이트 점수가 작게 나와도 정상으로 본다. B·D는 1990년대 이후 자료라 기본 게이트(A1~A10)만으로 판정하고, 1960~85 재확인은 자료가 없어 해당 없음(미검증으로 기록). COT TFF(2006~)·소매 MMF(WRMFNS)·AAII 수정 파일은 이번 스텝에서 쓰지 않는다. 자료 이용 조건: COT·SLOOS는 미국 정부 공공 자료, VIX3M은 FRED 재게시(Cboe 허락) 연구용. 3배 레버리지·TLT/금·S21 C 충격 이탈 기억 제외.
