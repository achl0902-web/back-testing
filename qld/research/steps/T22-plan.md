# T22 조합 전수 탐색 결과 확인 — 사전 등록 (2026-10-24, 확인 계산 전 커밋)

T21에서 ELEMENTS 풀 5개(MW·X4·HK·VRS·WR)의 부분집합 31개를 `candidates/POOL.js`로 전수 채점했다(탐색, trials.jsonl에 31회 기록). 상위를 골라 본 것이므로 그대로 채택하지 않고 아래 기준으로 확인한다.

## 확인 대상 (값 고정, 다시 고르지 않음)
- P1 = MW,X4,HK,VRS,WR (전수 1위 +1.65)
- P2 = X4,VRS,WR (MW 없이 가장 고른 개선: 다섯 세트 중앙·최악 모두 ≥ 0, +1.31)

## 채택 기준 (모두 만족)
1. 배터리 A1~A10, 시도 수 31 → A2는 2배 기준(k2=2).
2. 1960~85 S&P 2배 재확인(`lib/histcheck.js`): 10년·5년 모두 챔피언 이상. VRS는 그 시대 자료(VIX 1990~, SKEW 1990~)가 없어 꺼지므로 MW·X4·HK·WR 몫만 검증, VRS 몫은 미검증으로 표시.
3. 2011~ 재확인(`lib/recentcheck.js`): 나스닥·S&P 2배 모두 우위 구간 절반 초과 + 최악 IRR 챔피언 이상.
4. 통과해도 채택은 사용자 결정(D 행). 페이지·알림은 승인 뒤.
