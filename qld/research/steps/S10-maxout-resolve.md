# S10 · S09 보류(maxOut 120) 해소

- 진행: 2026-10-18 · 데이터: 나스닥100·QLD 2026-10-15, 해외 지수 2026-10-16
- 목표: maxOut 120의 이득이 진짜인지 가린다. (1) 이득의 원천 분리: 타임아웃 복귀 뒤 보유 기간을 줄여도 남는가 (2) 분할 복귀로 하방을 줄이면서 이득을 지키는가 (3) 독립 약세장(해외 지수 합성 2배)에서 재현되는가.

## 준비

- 엔진에 `holdTimeout`(타임아웃 복귀 뒤 보유 일수, 기본 = hold 40)과 `reFracTimeout`(타임아웃 복귀 때 넣는 현금 비율, 나머지는 정상 복귀 조건 때) 추가. `enginecheck` 670개 차이 0.
- 연결 확인 3회(기록됨): maxOut 120 → 1.94 · holdTimeout 0 → 0.43 · reFracTimeout 0.5 → 0.82.
- 새 도구 `lib/intl.js`: 닛케이225, DAX, FTSE100, 항셍, 코스피의 가격지수로 합성 2배(배당 없음 → 보수적, 미국 3개월 금리+0.5% 차입, 보수 0.95%, 원화 환산과 매크로 경보는 나스닥 데이터 날짜 기준). 고정 검증 세트를 바꾸지 않는 **추가 증거**.

## 사전 등록 (진행자 격자, 실행 전 기록)

- maxOut ∈ {96, 120, 144, 180, 250} × holdTimeout ∈ {0, 20, 40} × reFracTimeout ∈ {0.5, 1} = 30개
- 각 설정은 표준 점수(나스닥·S&P)와 해외 5개 시장 Δ(챔피언 대비)를 함께 본다.
- 성공 기준: 표준 점수 > 0 이 maxOut 이웃값(96~144) 전반에서 유지 + 해외에서 달라진 구간 중 승이 패보다 많고 해외 Δ중앙 합이 양수.

## 1. 격자 결과 (30개, `steps/S10-grid.json`)

(각 칸은 frac 0.5 / frac 1. 해외 승패는 겹치는 10년 구간 수라 실제 독립 사건은 시장당 1~2개)

- 보유 기간을 0으로 줄이면 효과가 대부분 사라짐(1.94 → 0.43): 이득은 타임아웃 복귀 자체보다 그 뒤 40일 강제 보유에서 나옴(비평가 S09 지적 확인).
- 분할 복귀(frac 0.5)는 이득을 절반 이하로 줄임.
- 120일 밖에서는 고원이 아님: 144에서 0.38, 180에서 음수.
- 해외 증거는 작고 섞임: 효과가 나는 시장마다 방향이 다름.
