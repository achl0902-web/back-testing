# T08 새 시대 검증 (1960~1985) — 사전 등록 (2026-10-20, 계산 전 커밋)

목적: 연구에 한 번도 쓰지 않은 시대(1960~85: 1966·1969~70·1973~74 약세장, 1970년대 인플레이션, 1980~82 고금리)에서 **규칙을 바꾸지 않고** 최종 전략 v1을 검증한다. 결과를 보고 문턱을 고르지 않는다.

## 데이터 (qld/research/data/hist)
- **S&P 2배 (주 시험)**: S&P500 일별 종가(1955~1985, 1955~60은 지표 준비) + 쉴러 월간 배당(D/P를 일할) = 총수익. 2배 합성은 기존과 같은 식(2×일간 수익 − (3개월 금리+0.5%) − 연 0.89% 보수). 금리는 TB3MS(월간, 전달 값).
- **나스닥 종합 2배 (보조)**: 1971~1985 일별 종가, 배당 0%(하한)와 S&P 배당률(상한) 두 가지. 나스닥100은 1985년 시작이라 대신 씀.
- 환율: 고정(원화 환산 효과 없음, 세금은 같은 규칙).
- 매크로 경보: 같은 macro.py로 계산, 그 시대에 있는 지표만(BAA 스프레드·3개월 확대·BAA-AAA·장단기차 재가팽창·기준금리 인하·삼의 법칙, 1967~ 실업수당, 1971~ NFCI 위험). 월간 금리는 그달이 끝난 뒤부터 쓰도록 한 달 늦춤. 5개 이상 있을 때만 경보 비율 계산(기존 규칙).

## 비교
최종 전략 v1 · 기술 4축만 · 단순 적립, 주 100만원, 비용 기본값. (참고) 노출 조절.
- S&P 2배: 10년 구간 1961~1975 시작, 5년 구간 1961~1980 시작, 1월·7월 시작.
- 나스닥 종합 2배: 5년 1973~1980 시작, 10년 1973~1975 시작.
- 사례(3~4년): 1965~67, 1968~71, 1972~75, 1980~83.

## 판정 (S&P 2배 5년·10년 각각)
최종 전략 v1이 **(a) 최악 IRR ≥ 단순 적립 최악 (b) IRR 중앙 ≥ 단순 적립 − 1%p (c) MDD 중앙이 단순 적립보다 얕음**을 모두 만족하면 "새 시대에서도 통함". (a)·(c)만 만족하면 "보험으로서는 통함", (a)도 실패하면 "1970년대형 장세에서는 약함". 나스닥 종합은 보조로 같은 기준을 보고만 한다.

사례 IRR (최종 v1 / 단순 적립): 1965~67 4.2 / 10.1 · 1968~71 8.1 / 6.2 · **1972~75 0.3 / −5.5** · 1976~79 3.0 / 6.0 · 1980~83 19.9 / 17.9.
- 1973~74 약세장: 1973-11-21 이탈(고점 대비 이미 하락 뒤) → 1974-01 복귀 → 1974-07 재이탈 → 1974-11 복귀. 첫 하락은 못 막지만 깊은 구간은 피함.
- 약점: 매크로 지표가 적어 1~2일짜리 이탈·복귀가 잦음(1961~85 이탈 31회, 그중 다수가 다음 날 복귀). 1965~67·1976~79처럼 완만한 장에서 단순 적립보다 3~6%p 낮음.
- 기술 4축만도 비슷한 성적(10년 4.5/−10.0, 5년 5.1/−19.3) → 이 시대에서도 핵심은 기술 축.

결론: T06(전진 검증)에서 의심된 것과 달리, 문턱을 그대로 둔 채 처음 보는 시대에서 **최악·MDD 보호가 재현**됐다. 수익 우위는 거의 없다(중앙 ±0.5%p) → "하락장 보험" 해석이 두 시험에서 일관.
