데이터와 가정
  • 데이터: 1985년 10월 ~ __LASTDATE__ 나스닥100 일간 종가, QQQ 배당 포함 수익률(1999년 3월 이전은 지수 + 연 0.3%로 근사), 미국 3개월 국채금리, 원/달러 일간 환율(FRED H.10).
  • QLD 수익률: QQQ 일간 수익률의 2배 − (3개월 금리 + 0.5%)의 차입비용 − 연 0.95% 보수. 같은 방식의 3배 버전은 2010~2026년 실제 TQQQ와 연복리 42.4% 대 42.5%로 맞습니다. QLD 상장(2006년) 이전 구간은 이 합성값입니다.
  • SGOV: 3개월 국채금리 − 0.1%, 분배금에 배당소득세 15.4%를 뗀 뒤 재투자.
  • 매매: 신호는 종가 기준, 체결은 다음 거래일 종가. 적립은 매주 첫 거래일, 원화를 환전 스프레드를 내고 달러로 바꿔 매수합니다.
  • 세금: 종목별 선입선출로 원화 취득가 대비 양도차익 계산, QLD와 QQQ 손익 통산, 연 기본공제 차감 후 세율 적용, 다음 해 6월 계좌의 SGOV(부족하면 QQQ, QLD 순서로 매도)에서 납부.
  • 하베스팅: 12월 마지막 거래일에 남은 공제 한도만큼 차익이 나도록 오래된 물량부터 팔고 즉시 재매수. 손실만 실현돼 공제가 낭비되는 경우는 건너뜁니다.
  • 자동 갱신: GitHub Actions가 평일 아침(한국시간 07:30 무렵) 전날 미국 종가를 Yahoo Finance에서 받아(실패하면 공개 GitHub 데이터 저장소) 이 페이지를 다시 만듭니다. 변동성이 30%를 넘거나 상태가 바뀌면 저장소에 알림 이슈를 엽니다.
