# QLD 변동성 적립 백테스터

매주 QLD를 적립하면서, 나스닥100의 변동성이 높아지면 SGOV로 피했다가 단계적으로 돌아오는 규칙을 단순 적립과 비교하는 페이지입니다. GitHub Actions가 평일 아침마다 전날 미국 종가로 페이지를 다시 만들고, 신호가 바뀌면 알림 이슈를 엽니다.

## 전략 프리셋

| 프리셋 | 이탈 | 복귀 | 강한 장 |
|---|---|---|---|
| 방어형 (기본) | 20일 변동성 > 35% | 최고치의 67% 아래면 1/3, 25% 아래면 전량 | 길게 끄는 하락장 (2000~02, 2008) |
| 균형형 | 변동성 > 35% 이고 50일선 아래 | 50일선 회복 또는 변동성 < 25% | 그 사이 |
| 반등형 | 변동성 > 40% 이고 20일선 아래 | 20일선 회복 또는 변동성 < 25% | 급락 후 V자 반등 (2020, 2025) |

이평선·MACD·RSI·모멘텀·고점 대비 낙폭 등 64가지 규칙을 같은 조건(매일 종가, 세후, 나스닥100·S&P500의 모든 5·10년 적립 구간)으로 비교한 결과, 어떤 규칙도 V자 반등과 긴 하락장을 동시에 잘 막지 못했고 위 세 가지가 각 성향의 대표였습니다.

## 방어형 규칙 상세

1. 매주 정해진 금액으로 QLD를 삽니다.
2. 매일 종가 기준으로 나스닥100의 20일 변동성(연환산)을 확인합니다.
3. 35%를 넘으면 다음 거래일에 QLD를 전량 SGOV로 옮기고, 적립금도 SGOV에 넣습니다.
4. 이탈 중 변동성이 이탈 후 최고치의 67% 아래로 내려오면 SGOV의 1/3을 QLD로 옮깁니다.
5. 25% 아래로 내려오면 전부 QLD로 옮깁니다.
6. 12월에 남은 양도세 기본공제(250만원) 한도만큼 팔고 바로 다시 삽니다.

세금(선입선출, 연 250만원 공제, 22%, 다음 해 6월 납부), 원/달러 환율, 수수료, 환전 스프레드를 모두 반영합니다. 페이지에서 기간·적립액·규칙 값을 바꿔 가며 비교할 수 있습니다.

## 처음 설정 (한 번만)

1. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다. 저장소 루트의 기존 페이지(`index.html`)도 같은 워크플로가 함께 배포합니다.
2. **Settings → Actions → General → Workflow permissions**를 **Read and write permissions**로 바꾸고 저장합니다.
3. **Actions** 탭에서 *qld-daily-update*를 열고 **Run workflow**를 누릅니다. 몇 분 뒤 `https://achl0902-web.github.io/back-testing/qld/` 에서 열립니다. 기존 페이지는 `https://achl0902-web.github.io/back-testing/` 그대로입니다.

## 알림 받기

신호가 바뀌거나 20일 변동성이 30%를 넘으면 저장소에 이슈가 열립니다. 저장소 오른쪽 위 **Watch → Custom → Issues**를 켜고 GitHub 모바일 앱 알림을 허용하면 휴대폰으로 받습니다.

## 자동 실행

- 평일 22:30 UTC(한국시간 화~토 07:30)에 실행됩니다. GitHub 사정으로 수십 분 늦어질 수 있습니다.
- 데이터는 Yahoo Finance(`^NDX`, `QQQ`, `KRW=X`, `^IRX`)에서 받고, 실패하면 공개 GitHub 저장소(specterz/tqqq_161ma, kydchen/qqq-tqqq-signal-dashboard, datasets/exchange-rates)를 씁니다.
- 매일 `data/status.json`을 커밋하므로 저장소가 활동 중으로 유지되어 예약 실행이 꺼지지 않습니다.

## 파일

| 경로 | 내용 |
|---|---|
| `data/base.json` | 1985-10 ~ 2026-10-15 일간 데이터 (나스닥100, QQQ 수익률, 3개월 금리, 원/달러) |
| `data/status.json` | 마지막 실행의 변동성과 상태 |
| `src/engine.js` | 백테스트 엔진 (페이지와 신호 계산이 같은 코드를 씀) |
| `src/page_tpl.html` | 페이지 템플릿 |
| `scripts/build.py` | 최신 데이터 추가, 페이지 생성, 신호·알림 계산 |
| `../.github/workflows/qld-update.yml` | 매일 실행과 Pages 배포 (저장소 루트) |

직접 실행: `python3 scripts/build.py` (Python 3.10+, Node 18+, 선택적으로 `pip install yfinance pandas`) 후 `site/index.html`을 엽니다.

## 주의

- 2006년 QLD 상장 이전 구간은 QQQ 수익률의 2배에서 차입비용(3개월 금리 + 0.5%)과 보수 0.95%를 뺀 합성값입니다.
- 과거 결과는 미래를 보장하지 않으며, 이 페이지와 알림은 규칙을 계산해 보여줄 뿐 투자 권유가 아닙니다.
