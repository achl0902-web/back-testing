# QLD 방어 적립 백테스터

평소에는 매주 QLD를 사고, 위험 신호가 겹치면 QLD를 모두 팔아 SGOV(단기 국채)로 피했다가 진정되면 전부 QLD로 돌아가는 규칙을, 매주 QLD를 사는 단순 적립과 비교하는 페이지입니다. GitHub Actions가 평일 아침마다 전날 미국 종가로 페이지를 다시 만들고, 다음 거래일에 이탈·복귀해야 하는 날이면 알림 이슈를 엽니다.

## 기본 전략: 최종 전략 v1 (2026-10-19부터 페이지 기본·알림 기준)

연구 단계(`research/`)에서 채택한 챔피언입니다. 매일 종가로 판단하고 다음 거래일 종가에 매매합니다.

- **이탈 (QLD 전량 → SGOV)**: 기술 4축 중 2개 이상이 켜지거나(복귀 후 40거래일 안에는 3개 이상) 매크로 경보 비율이 50%를 새로 넘을 때
  - ① 변동성: 20일 하방 변동성 30% 초과 또는 상방 35% 초과 ② 급락: 10거래일 −8% 이하 ③ 추세: 주봉 RSI 45 미만 ④ 급팽창: 10일 변동성이 60일 변동성의 1.6배 초과
- **이탈 중**: 적립금은 SGOV에 쌓습니다.
- **복귀 (SGOV 전량 → QLD)**: 켜진 축 1개 이하 · 나스닥100이 20일선 위 · 10일 변동성 < 60일 변동성일 때

노출 조절(변동성 계단표)과 비교한 결과와 채택 이유는 `research/LEDGER.md`에 있습니다(2026-10-19 비교: 5개 검증 세트 중 4개에서 우세). 기간별 성적은 페이지의 '검증 성적' 표를 보세요.

## 2.0에서 바뀐 것 (2026-10-20, `research/steps/V2-plan.md`)

- **알림·페이지 판정 일치**: 주 중간에는 주봉 RSI를 지난 완성 주로 계산합니다(전에는 미완성 주 종가를 써서 백테스트와 120일 판정이 달랐음). 페이지 '지금'과 매일 알림이 엔진의 같은 함수(`nextAction`)로 다음 거래일 매매를 정합니다.
- **데이터 보존**: 매일 받은 종가를 `data/base.json`에 누적 저장합니다.
- **화면**: 기술 축마다 문턱까지의 거리 막대, 평가액 차트의 이탈 구간, 이탈 성적표(이탈마다 피한 하락·놓친 상승), 연도별 수익률.
- **V2 후보(승인 대기)**: 이탈 중 SGOV 대신 7~10년 국채(IEF 합성)를 보유. 매매 날짜는 같고 숫자 기준을 모두 통과했지만 2022년형 금리 인상기에는 손해. 페이지 '전략'에서 비교만 할 수 있고, 알림은 v1 그대로입니다.
- 테스트: `node --test qld/src/engine.test.js` (잘린 데이터의 판정 = 백테스트 다음 날 매매).

## 비교용 규칙 (페이지에서 선택)

- **v1 + 이탈 중 중기 국채 (V2 후보)**: 위 규칙 그대로, 이탈 대금과 이탈 중 적립금을 합성 IEF(10년 금리, 듀레이션 7.5, 이자 15.4% 원천징수)로 보유
- **기술 4축만**: 위 규칙에서 매크로 경보를 뺀 것
- **노출 조절 (참고, 이전 기본)**: 나스닥100 20일 변동성으로 노출을 0~2.5배 사이에서 정합니다(TQQQ·QQQ·SGOV). 줄일 땐 바로, 늘릴 땐 경계보다 3%p 더 낮아야 올리고, 보유 노출이 목표와 0.5배 이상 다르면 다음 거래일 종가에 맞춥니다.

| 나스닥100 20일 변동성 | 노출 | TQQQ | QQQ | SGOV |
|---|---|---|---|---|
| 25% 미만 | 2.5배 | 75% | 25% | 0% |
| 25~35% | 2배 (QLD와 같음) | 50% | 50% | 0% |
| 35~45% | 1배 | 0% | 100% | 0% |
| 45% 이상 | 0배 | 0% | 0% | 100% |

**매크로 14개** (매크로 경보 비율 계산에 사용, 지표별 발표 시차 반영: 시장 1일, 주간 5~6일, 삼의 법칙 36일): BAA 스프레드, BAA 스프레드 3개월 확대, BAA-AAA, 장단기차(10Y-3M) 3개월 재가팽창, 기준금리 6개월 인하폭, 세인트루이스 금융스트레스, NFCI 위험, TED(2022 종료), VIX/VIX3M, 실업수당 4주평균 전년비, 실시간 삼의 법칙, 달러 6개월 상승, 소형주/대형주 6개월 부진, 구리/금 6개월 하락. 계산은 `scripts/macro.py`.

페이지에서 처음 한 번 넣는 거치금과 주간 적립액을 함께 정할 수 있습니다. 적립액을 0으로 두면 거치식이 되고, 비교 기준도 ‘단순 보유’로 바뀝니다.

연말에는 남은 양도세 기본공제(250만원) 한도만큼 팔고 바로 다시 삽니다. 세금(선입선출, 22%, 다음 해 6월 납부), 원/달러 환율, 수수료, 환전 스프레드를 모두 반영합니다.

## 비교 페이지: 3배+1배 섞기 vs 2배 (`hold.html`)

TQQQ+QQQ 대 QLD, UPRO+SPY 대 SSO를 같은 날 같은 돈으로 적립·거치해 세후 청산가치로 비교합니다. 기본 규칙: 계좌 전체 노출이 2.45배를 넘으면 새 적립금은 SGOV로, 2.55배를 넘으면 3배를 팔아 2배로(판 돈은 SGOV), 1.65배 밑이면 SGOV로 3배를 사서 2배로 올립니다. 2배 밑일 땐 적립금을 3배 쪽에 더 넣습니다. 연말엔 공제 한도만큼 하베스팅합니다(2배 계좌도 똑같이).

- QQQ 계열 적립 10년 구간에서 QLD를 이긴 비율: 1987~ 86%, 1999~ 81%, 2010~ 81% (IRR 중앙 +1.3~2.0%p). 5년 구간 69~70%.
- S&P 계열(같은 규칙)은 이점이 작습니다: 적립 10년 1987~ 64%, 1999~ 75%, 2010~ 36%(−0.2%p). 변동성이 낮아 3배 쪽 표류 이득이 작고 1배 쪽 배당 원천징수가 큽니다.
- 기준값 45개 조합을 2009년까지로 고르고 2010년 이후로 시험하면 순위 상관이 −0.35라, 기준값 미세 조정은 의미가 없습니다. 규칙 모양 자체는 45개 중 30개가 시험 구간에서 60% 넘게 이겼습니다.

## 처음 설정 (한 번만)

1. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다. 저장소 루트의 기존 페이지(`index.html`)도 같은 워크플로가 함께 배포합니다.
2. **Settings → Actions → General → Workflow permissions**를 **Read and write permissions**로 바꾸고 저장합니다.
3. **Actions** 탭에서 *qld-daily-update*를 열고 **Run workflow**를 누릅니다. 몇 분 뒤 `https://achl0902-web.github.io/back-testing/qld/` 에서 열립니다. 기존 페이지는 `https://achl0902-web.github.io/back-testing/` 그대로입니다.

## 알림 받기

최종 전략 v1이 다음 거래일 종가에 이탈하거나 복귀해야 하면 저장소에 이슈가 열립니다(제목에 '이탈: QLD 전량 매도 → SGOV' 또는 '복귀: SGOV 전량 → QLD'). 저장소 오른쪽 위 **Watch → Custom → Issues**를 켜고 GitHub 모바일 앱 알림을 허용하면 휴대폰으로 받습니다.

## 자동 실행

- 평일 22:30 UTC(한국시간 화~토 07:30)에 실행됩니다. GitHub 사정으로 수십 분 늦어질 수 있습니다.
- 매크로 지표는 FRED API(저장소 Secret `FRED_API_KEY`)와 Yahoo Finance에서 받아 `data/macro/`에 커밋합니다. 실패하면 저장된 값을 씁니다.
- 가격 데이터는 Yahoo Finance(`^NDX`, `QQQ`, `KRW=X`, `^IRX`, `^VIX`)에서 받고, 하나라도 비면 그때만 공개 GitHub 저장소(specterz/tqqq_161ma, kydchen/qqq-tqqq-signal-dashboard, datasets/exchange-rates)를 받아 채웁니다. 둘 다 있으면 Yahoo 값을 씁니다.
- 매일 `data/status.json`을 커밋하므로 저장소가 활동 중으로 유지되어 예약 실행이 꺼지지 않습니다.

## 파일

| 경로 | 내용 |
|---|---|
| `data/base.json` | 1985-10부터 일간 데이터 (나스닥100, QQQ 수익률, 3개월 금리, 원/달러), 매일 실행이 새 종가를 덧붙임 |
| `data/status.json` | 마지막 실행의 상태(보유·이탈), 기술 4축·매크로 경보, 다음 거래일 할 일 |
| `data/macro/` | 매크로 원자료 (FRED, Yahoo) |
| `scripts/macro.py` | 매크로 경보 비율 계산 |
| `scripts/fetch_macro.py` | 매크로 원자료 다운로드 |
| `src/engine.js` | 백테스트 엔진 (페이지와 신호 계산이 같은 코드를 씀, 다음 거래일 판정 `nextAction`) |
| `src/engine.test.js` | 판정 일치·주봉 RSI 테스트 |
| `src/page_tpl.html` | 메인 페이지 템플릿 |
| `src/hold_tpl.html` | 비교 페이지(`hold.html`) 템플릿 |
| `src/ui.css`, `src/ui.js` | 두 페이지가 함께 쓰는 스타일과 화면 코드(숫자 표시, 캔버스 차트, 기간 막대, 바로 가기·폰 요약) |
| `scripts/build.py` | 최신 데이터 추가, 페이지 생성, 신호·알림 계산 |
| `../.github/workflows/qld-update.yml` | 매일 실행과 Pages 배포 (저장소 루트) |

직접 실행: `python3 scripts/build.py` (Python 3.10+, Node 18+, 선택적으로 `pip install yfinance pandas`) 후 `site/index.html`을 엽니다. `--offline`을 붙이면 새 데이터를 받지 않고 저장된 데이터로만 만듭니다(화면 수정 확인용).

## 주의

- 2006년 QLD 상장 이전 구간은 QQQ 수익률의 2배에서 차입비용(3개월 금리 + 0.5%)과 보수 0.95%를 뺀 합성값입니다. TQQQ는 3배 − 2 × (3개월 금리 + 0.5%) − 보수 0.84%로, 2010년 상장 이전은 합성값입니다.
- 과거 결과는 미래를 보장하지 않으며, 이 페이지와 알림은 규칙을 계산해 보여줄 뿐 투자 권유가 아닙니다.
