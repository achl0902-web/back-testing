# QLD 노출 조절 백테스터

매주 적립하면서 나스닥100 노출을 0~3배 사이에서 조절하고(TQQQ·QQQ·SGOV), 매주 QLD를 사는 단순 적립과 비교하는 페이지입니다. GitHub Actions가 평일 아침마다 전날 미국 종가로 페이지를 다시 만들고, 비중을 바꿔야 하는 날이면 알림 이슈를 엽니다.

## 기본 전략: 노출 조절 (변동성 계단표)

방향은 예측하지 않습니다. 이전 규칙들의 신호(변동성, 급락, RSI, 매크로 등)는 다음 한 달 수익률과의 순위상관이 ±0.14 이내로 기간마다 부호가 바뀌었지만, 다음 한 달 변동성은 잘 맞혔습니다(20일 변동성 0.57~0.76). 레버리지 상품은 변동성이 클수록(제곱에 비례) 깎이므로, 예측되는 변동성만으로 노출을 정합니다.

| 나스닥100 20일 변동성 | 노출 | TQQQ | QQQ | SGOV |
|---|---|---|---|---|
| 25% 미만 | 2.5배 | 75% | 25% | 0% |
| 25~35% | 2배 (QLD와 같음) | 50% | 50% | 0% |
| 35~45% | 1배 | 0% | 100% | 0% |
| 45% 이상 | 0배 | 0% | 0% | 100% |

- **줄일 땐 바로, 늘릴 땐 3%p 여유**: 경계를 넘으면 즉시 한 칸 내리고, 올릴 때는 변동성이 경계보다 3%p 더 낮아야 올림(경계 근처 잦은 매매 방지)
- **매매**: 매일 전날 종가로 목표를 정하고, 보유 노출이 목표와 0.5배 이상 다르면 다음 거래일 종가에 맞춤. 그 사이 적립금은 마지막으로 맞춘 비중대로 매수. 평균 연 2~4회
- 페이지에서 **상승장 우선**(45% 이상도 0.5배), **낙폭 우선**(20/30/40% 경계, 조정 폭 0.75배, 여유 5%p), **켈리**(기대수익 ÷ 변동성², 최대 3배)를 고를 수 있음

**왜 매달이 아니라 매일 확인인가**: 매달·3개월·6개월 확인은 결과가 확인 날짜에 크게 좌우됐습니다(같은 '4주마다'라도 시작 주에 따라 2006년 이후 10년 구간 중앙 격차가 -6.9%p ~ +3.1%p). 매일 확인하되 크게 어긋날 때만 사고팔면 날짜 운이 사라지고 매매 횟수도 적습니다.

## 검증 (세후, 주 70만원, 기준은 미리 고정)

기준: 나스닥100·S&P500 각각 1987~95년 시작·2006~16년 시작 10년 적립 구간에서 ① 최저 IRR이 단순 적립보다 높고 ② 중앙 격차 ≥ 0.

| | 나스닥100 1987~ | 나스닥100 2006~ | S&P500 1987~ | S&P500 2006~ |
|---|---|---|---|---|
| 균형 계단표 | ✓ 중앙 +17.9%p, 최저 11.0% (단순 -9.8%) | ✓ +3.0%p, 21.8% (19.2%) | ✗ +2.4%p, -5.0% (3.0%) | ✓ +2.5%p, 15.1% (12.7%) |
| 켈리 최대 3배 | ✓ +6.0%p | ✓ +5.7%p | ✗ | ✓ +1.0%p |
| 이전 최종 | ✓ | ✓ +0.4%p | ✗ | ✗ |

한 번에 쭉 적립했을 때(나스닥100, 세후 IRR / 시간가중 MDD): 1999년~ 24.3% / -76% (단순 22.1% / -99%), 2006년~ 29.9% / -61% (28.8% / -70%), 2010년~ 31.5% / -61% (31.4% / -61%). 경계값을 ±2~3%p 옮기거나 여유를 0~5%p로 바꿔도 같은 판정이었습니다.

남은 약점: ① 2000~02년 S&P500처럼 변동성이 낮은 채 천천히 빠지는 하락장 ② 2010년 이후 최대 낙폭(2022년)은 단순 적립과 비슷 ③ 잔잔할 때 2.5배라 1987년 10월 19일 같은 하루 폭락에 약함(하루 약 -37%) ④ TQQQ 상장(2010년) 이전은 합성 데이터.

## 이전 규칙 (페이지에서 비교용으로 선택 가능)

**이전 최종** — 기술 4축(20일 하방 변동성 > 30% 또는 상방 > 35%, 10거래일 -8%, 주봉 RSI < 45, 10일/60일 변동성 > 1.6) 중 2개 이상 또는 매크로 경보 비율이 50%를 새로 넘으면 QLD 전량 → SGOV, 켜진 축 1개 이하 · 20일선 위 · 10일 변동성 < 60일 변동성이면 복귀. 파라미터가 과최적화되어 있었고(과거 자료만으로 다시 고르면 2006년 이후 단순 적립보다 낮음) S&P500에서는 단순 적립을 넘지 못했습니다.

**매크로 14개** (상한 옵션과 이전 규칙에 사용, 지표별 발표 시차 반영: 시장 1일, 주간 5~6일, 삼의 법칙 36일): BAA 스프레드, BAA 스프레드 3개월 확대, BAA-AAA, 장단기차(10Y-3M) 3개월 재가팽창, 기준금리 6개월 인하폭, 세인트루이스 금융스트레스, NFCI 위험, TED(2022 종료), VIX/VIX3M, 실업수당 4주평균 전년비, 실시간 삼의 법칙, 달러 6개월 상승, 소형주/대형주 6개월 부진, 구리/금 6개월 하락. 계산은 `scripts/macro.py`.

페이지에서 처음 한 번 넣는 거치금과 주간 적립액을 함께 정할 수 있습니다. 적립액을 0으로 두면 거치식이 되고, 비교 기준도 ‘단순 보유’로 바뀝니다.

연말에는 남은 양도세 기본공제(250만원) 한도만큼 팔고 바로 다시 삽니다. 세금(선입선출, 22%, 다음 해 6월 납부), 원/달러 환율, 수수료, 환전 스프레드를 모두 반영합니다.

## 처음 설정 (한 번만)

1. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다. 저장소 루트의 기존 페이지(`index.html`)도 같은 워크플로가 함께 배포합니다.
2. **Settings → Actions → General → Workflow permissions**를 **Read and write permissions**로 바꾸고 저장합니다.
3. **Actions** 탭에서 *qld-daily-update*를 열고 **Run workflow**를 누릅니다. 몇 분 뒤 `https://achl0902-web.github.io/back-testing/qld/` 에서 열립니다. 기존 페이지는 `https://achl0902-web.github.io/back-testing/` 그대로입니다.

## 알림 받기

노출 조절 규칙상 보유 노출이 목표와 조정 폭(0.5배) 이상 어긋나 다음 거래일에 비중을 바꿔야 하면 저장소에 이슈가 열립니다(제목에 목표 배수와 TQQQ·QQQ·SGOV 비중). 저장소 오른쪽 위 **Watch → Custom → Issues**를 켜고 GitHub 모바일 앱 알림을 허용하면 휴대폰으로 받습니다.

## 자동 실행

- 평일 22:30 UTC(한국시간 화~토 07:30)에 실행됩니다. GitHub 사정으로 수십 분 늦어질 수 있습니다.
- 매크로 지표는 FRED API(저장소 Secret `FRED_API_KEY`)와 Yahoo Finance에서 받아 `data/macro/`에 커밋합니다. 실패하면 저장된 값을 씁니다.
- 가격 데이터는 Yahoo Finance(`^NDX`, `QQQ`, `KRW=X`, `^IRX`)에서 받고, 실패하면 공개 GitHub 저장소(specterz/tqqq_161ma, kydchen/qqq-tqqq-signal-dashboard, datasets/exchange-rates)를 씁니다.
- 매일 `data/status.json`을 커밋하므로 저장소가 활동 중으로 유지되어 예약 실행이 꺼지지 않습니다.

## 파일

| 경로 | 내용 |
|---|---|
| `data/base.json` | 1985-10 ~ 2026-10-15 일간 데이터 (나스닥100, QQQ 수익률, 3개월 금리, 원/달러) |
| `data/status.json` | 마지막 실행의 목표 노출·비중, 이전 규칙의 기술 4축·매크로 경보 |
| `data/macro/` | 매크로 원자료 (FRED, Yahoo) |
| `scripts/macro.py` | 매크로 경보 비율 계산 |
| `scripts/fetch_macro.py` | 매크로 원자료 다운로드 |
| `src/engine.js` | 백테스트 엔진 (페이지와 신호 계산이 같은 코드를 씀) |
| `src/page_tpl.html` | 페이지 템플릿 |
| `scripts/build.py` | 최신 데이터 추가, 페이지 생성, 신호·알림 계산 |
| `../.github/workflows/qld-update.yml` | 매일 실행과 Pages 배포 (저장소 루트) |

직접 실행: `python3 scripts/build.py` (Python 3.10+, Node 18+, 선택적으로 `pip install yfinance pandas`) 후 `site/index.html`을 엽니다.

## 주의

- 2006년 QLD 상장 이전 구간은 QQQ 수익률의 2배에서 차입비용(3개월 금리 + 0.5%)과 보수 0.95%를 뺀 합성값입니다. TQQQ는 3배 − 2 × (3개월 금리 + 0.5%) − 보수 0.84%로, 2010년 상장 이전은 합성값입니다.
- 과거 결과는 미래를 보장하지 않으며, 이 페이지와 알림은 규칙을 계산해 보여줄 뿐 투자 권유가 아닙니다.
